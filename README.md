# DataCamp Projects

**Note:** This repository brings together the applied projects I completed throughout the certification tracks from [DataCamp](https://www.datacamp.com/) — all technical content completed entirely in English. Each folder contains a standalone project, with its own notebook/script and, where applicable, the data used.

## About

These projects were developed as part of the DataCamp certifications I completed (Python Programming Fundamentals, Python Programming, Associate Python Developer, Python Developer, Associate AI Engineer, and Associate Data Scientist in Python), covering data analysis and visualization, automation, AI API integration, and Python coding best practices.
